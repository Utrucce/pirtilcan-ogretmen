# Pıtrak Nüsha

Soru bankası, test kitabı ve deneme hazırlama atölyesi. Derleme gerektirmeyen, saf statik bir PWA'dır.

## Render'a yükleme
1. Bu klasörün **içindekileri** (index.html bu dosyayla aynı seviyede olmalı) GitHub deposuna yükle.
2. Render → **New → Static Site** → depoyu seç.
3. Build Command: boş bırak · Publish Directory: `.`
4. Deploy. Bitti.

(Alternatif: depoda `render.yaml` var; Blueprint olarak da kurulabilir.)
